# Apple Website Clone

This project is a front-end UI clone of the Apple website, built using HTML and CSS.

## About the Project

I created this project to practice and showcase my front-end web development skills. The project focuses on recreating the layout and visual design of an e-commerce website using HTML and CSS.

## Features

- Apple-style navigation bar
- Search bar
- Product sections
- Product cards
- Hero section
- Multiple product images
- Responsive layout design
- Footer section

## Technologies Used

- HTML5
- CSS3

## Project Type

This is a static UI/UX project. It focuses on the front-end design and layout. Functional features such as login, search functionality, cart, and payment system are not implemented.

## Disclaimer

This project is a personal UI/UX clone created for educational and learning purposes only. It is not affiliated with, endorsed by, or connected to Apple.com, Inc.

This project is a static front-end design created using HTML5 and CSS3. No real login, payment, shopping, or user data collection functionality is implemented.
