# 🍎 Apple Website Clone (Static UI)

A pixel-perfect frontend clone of the official Apple website built purely using *HTML5* and *CSS3*. 

This project is a visual UI/UX showcase designed to demonstrate CSS layout techniques, styling accuracy, and web responsiveness.

> *Note:* This is a *static frontend project*. Since no JavaScript or backend is implemented, buttons, links, and forms are non-functional.

---

## 🚀 Features
* *Pure HTML & CSS:* No external frameworks or JavaScript libraries used.
* *Pixel-Perfect Styling:* Recreated Apple's modern, clean, and minimalist aesthetic.
* *Flexbox & CSS Grid:* Utilized modern layout techniques for accurate component positioning.

---

## 🛠️ Tech Stack
* *HTML5* (Semantic Structure)
* *CSS3* (Styling, Flexbox, Grid)
